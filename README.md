# Taller HTML + CSS + Git

Proyecto de práctica de Desarrollo de Software V.

## Archivos
- `index.html`: estructura de la página.
- `css/estilos.css`: estilos visuales de la página.

## Cómo abrir
Abre `index.html` con un navegador web.

## Cambios aplicados
1. Fondo de la página: `#fff8e7`.
2. Encabezado: `#512da8`.
3. Padding de tarjetas: `32px`.
4. Bordes redondeados: `20px`.
5. Tarjetas en una columna en todo momento.
6. Párrafos de las tarjetas a `1.05rem`.
7. El enlace cambia de color al pasar el puntero.
8. Indicador de foco visible para navegación con teclado.
